Every binary classifier's performance fits in a 2×2 table. Signal Detection Theory (WWII radar operators) → Medical diagnosis (Yerushalmy 1947) → Machine Learning today.

Memory trick: The second word is the prediction. The first word says if it was right.
"True Positive" = correctly predicted positive. "False Negative" = incorrectly predicted negative.

Core Metrics

Sensitivity (Recall / TPR)

Sensitivity = TP / (TP + FN)

"Of all who are actually sick, what % did we catch?"

Prioritize when: Missing a case is catastrophic (cancer screening, airport security).

Specificity (TNR)

Specificity = TN / (TN + FP)

"Of all who are actually healthy, what % did we correctly clear?"

Prioritize when: False alarms have serious consequences (criminal conviction, expensive tests).

Precision (PPV)

PPV = TP / (TP + FP)

"Of everyone we flagged positive, what % were real?"

The patient's question: "I tested positive — how worried should I be?"

The Lazy Classifier Trap

Accuracy = (TP + TN) / Total

A classifier that always says "negative" gets 97% accuracy when disease prevalence is 3%. It catches zero patients.

MCC fixes this: lazy classifier scores MCC = 0.00.

Key Formulas Summary

F1 = 2 × (Precision × Sensitivity) / (Precision + Sensitivity) — Harmonic mean, penalizes imbalance

MCC = (TP×TN − FP×FN) / √((TP+FP)(TP+FN)(TN+FP)(TN+FN)) — Gold standard for imbalanced data

NPV = TN / (TN + FN) — "I tested negative — how safe should I feel?"

Sensitivity–Specificity Tradeoff

A loan default model scores customers 0–100. Drag the threshold to see the tradeoff: catching more defaults (↑ sensitivity) means more false alarms (↓ specificity).

The Key Insight

There is no "best" threshold — only the best threshold for your costs. If missing a default costs $50,000 but investigating a false alarm costs $200, push the threshold lower (higher sensitivity). If false alarms cost $10,000 each, push it higher (higher specificity).
