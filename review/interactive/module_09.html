Hypotheses: H0 vs H1

H0 — The Null Hypothesis

"Nothing has changed. The status quo holds."

H0 is what we assume is true until the data convinces us otherwise. It always contains an equality (=, ≤, or ≥).

AIOS Example: "The mean GPU spot price is equal to $2.50/hr." We assume the current pricing model is correct.

H1 — The Alternative Hypothesis

"Something is different. There is an effect."

H1 is the claim we're testing — the research question. It's what we need evidence to support.

AIOS Example: "The mean GPU spot price is not equal to $2.50/hr." We suspect pricing has shifted.

Key rule: We never "accept" H0. We either reject H0 (evidence supports H1) or fail to reject H0 (insufficient evidence). Absence of evidence is not evidence of absence.

One-Tail vs Two-Tail Tests

Two-Tail Test

H1: μ ≠ μ0 (could be higher OR lower)

"Has GPU pricing changed from $2.50?"

Rejection region split between both tails. Use when you don't have a directional prediction.

One-Tail Test

H1: μ > μ0 (right-tail) or H1: μ < μ0 (left-tail)

"Has GPU pricing increased above $2.50?"

All rejection region in one tail. More statistical power for a specific direction.

The 5-Step Hypothesis Testing Framework

  1. State hypotheses: Write H0 and H1 clearly
  2. Choose α: Set significance level (usually 0.05)
  3. Compute test statistic: t or z from the data
  4. Find p-value: Probability of seeing data this extreme if H0 is true
  5. Make decision: If p ≤ α, reject H0. Otherwise, fail to reject.

Type I / Type II Error Tradeoff

Two overlapping distributions: the null (H0 true) and the alternative (H1 true). Changing α shifts the critical value, trading off between Type I and Type II errors.

The Tradeoff

  • Decrease α (more strict) → fewer false alarms (Type I ↓) but more missed signals (Type II ↑, Power ↓)
  • Increase α (more lenient) → more false alarms (Type I ↑) but fewer missed signals (Type II ↓, Power ↑)
  • Increase sample size → reduces standard error → both error types improve
  • Larger effect size → distributions separate → easier to detect (Power ↑)

T-Test Functions

=T.TEST(array1, array2, tails, type) → p-value for comparing two samples tails: 1 = one-tail, 2 = two-tail type: 1 = paired, 2 = equal var, 3 = unequal var (Welch)

Critical Values and Distribution

=T.INV.2T(alpha, df) → critical t-value (two-tail) =T.INV(alpha, df) → critical t-value (one-tail, left) =T.DIST.2T(t_stat, df) → two-tail p-value from t-statistic =T.DIST.RT(t_stat, df) → right-tail p-value from t-statistic

Z-Test (known population std dev)

=Z.TEST(array, hypothesized_mean, sigma) → one-tail p-value for Z-test =2*Z.TEST(array, hypothesized_mean, sigma) → two-tail p-value

Manual T-Statistic Formula

t = (x̄ - μ0) / (s / SQRT(n)) =(AVERAGE(range) - mu0) / (STDEV.S(range) / SQRT(COUNT(range)))

Proportion Test (Z-test for proportions)

z = (p̂ - p0) / SQRT(p0 * (1 - p0) / n) =(observed_proportion - hypothesized_p) / SQRT(hypothesized_p*(1-hypothesized_p)/n) =NORM.S.DIST(z, TRUE) → left-tail p-value =2*(1-NORM.S.DIST(ABS(z), TRUE)) → two-tail p-value
