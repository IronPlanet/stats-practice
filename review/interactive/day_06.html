What Is Probability?

Probability measures how likely an event is to occur, on a scale from 0 (impossible) to 1 (certain). Three approaches:

Classical (Theoretical)

P(A) = favorable outcomes / total outcomes

Works when all outcomes are equally likely. Example: P(heads) = 1/2.

Empirical (Relative Frequency)

P(A) = count of A / total observations

Based on observed data. "Out of 24 hours, how often does demand exceed 3,000 queries?"

Key Rules

Complement Rule

P(not A) = 1 - P(A)

The probability something does NOT happen. If P(rain) = 0.30, then P(no rain) = 0.70.

When to use: "At least one" problems are almost always easier as 1 - P(none).

Cumulative Probability

P(X ≤ k) = P(X=0) + P(X=1) + ... + P(X=k)

Add up individual probabilities from 0 through k. Excel's cumulative flag (TRUE) does this automatically.

Empirical Probability Distribution

Bin your data into categories, count the frequency of each bin, divide by total observations. The result is a probability distribution where all P(X) values sum to 1.0.

Steps:

  1. Define bins (ranges of values)
  2. Count observations in each bin → frequency
  3. Divide each frequency by total → P(X) = count / n
  4. Cumulative P: running sum of P(X) from first to last bin
  5. Expected Value: E(X) = SUMPRODUCT(midpoints, probabilities)

Binomial Distribution

Counts the number of successes in a fixed number of independent trials, each with the same probability of success.

Three Requirements

  1. Fixed number of trials (n) — you know how many times you're checking
  2. Two outcomes per trial — success or failure
  3. Constant probability (p) — same chance each trial

Excel Functions

=BINOM.DIST(k, n, p, FALSE) — P(exactly k successes)

=BINOM.DIST(k, n, p, TRUE) — P(at most k successes) — cumulative

=1 - BINOM.DIST(k, n, p, TRUE) — P(more than k successes) — complement

Connection: Empirical → Binomial

The empirical distribution gives you p (the probability of success per trial). Then the Binomial tells you what happens when you repeat that trial n times.

Example: If 10/24 hours are "Standard" demand (p = 10/24 = 0.417), what's the chance that exactly 4 out of 10 random hours are Standard?

Key Takeaway

Expected Value = SUMPRODUCT(midpoints, probabilities). It's the weighted average — the "center of gravity" of the distribution. It does NOT have to equal any actual bin midpoint.

Complement Trick

P(at least 1) = 1 - P(exactly 0)

This is almost always easier than adding up P(1) + P(2) + P(3) + ... Set k=0 below to see P(X=0), then subtract from 1.

Empirical Probability

=COUNTIFS(range, ">="&low, range, "<"&high) → count in bin =count / total → P(X) for that bin =SUMPRODUCT(midpoints, probabilities) → Expected Value =1 - SUM(P_first_k_bins) → Complement

Binomial Distribution

=BINOM.DIST(k, n, p, FALSE) → P(exactly k successes) =BINOM.DIST(k, n, p, TRUE) → P(at most k successes) =1 - BINOM.DIST(k, n, p, TRUE) → P(more than k successes) =1 - BINOM.DIST(0, n, p, FALSE) → P(at least 1 success)

Key Statistics

=n * p → Expected number of successes =n * p * (1 - p) → Variance =SQRT(n * p * (1 - p)) → Standard deviation
