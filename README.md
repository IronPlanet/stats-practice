# Stats Practice — BUS 322

Self-paced business-statistics practice: scenario questions, multiple choice,
an explanation after every answer. Miss one and it comes back until you beat
it. Progress and streaks are saved on your own device — nothing is collected.

**Practice here:** https://ironplanet.github.io/stats-practice/

Built from the BUS 322 question bank (Lynn University). The page is a single
static file generated by `build_practice.py` in the (private) LynnGames repo —
edit questions there, rebuild, and push here to update.
